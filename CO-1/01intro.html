Internet Fundamentals

Internet

The Internet is a global network that connects millions of computers.

Web vs Internet

The Internet is the network. The Web is a service that runs on the Internet.

HTTP

HTTP stands for HyperText Transfer Protocol. It transfers web data.

HTTPS

HTTPS is secure version of HTTP using encryption.

Client-Server Architecture

The client sends request and the server sends response.

Web Browser

Examples: Chrome, Edge, Firefox.

Domain Name

A domain is the address of a website (example.com).

Web Hosting

Hosting stores website files on a server.
